# SmartQ คิวรถ — หน้าจอคนขับ

แอปบนมือถือ (PWA) ให้คนขับดูคิวของรถตัวเอง และประตูขึ้นสินค้าหลังได้งาน

- เปิดที่: https://tr-dev-ops.github.io/smartq-driver/
- พิมพ์เลขทะเบียน 6 หรือ 7 หลักครั้งแรกครั้งเดียว แอปจะจำไว้
- เพิ่มลงหน้าจอหลักได้ (Android: เมนู ⋮ → ติดตั้งแอป / iPhone: ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม)

## ข้อมูลมาจากไหน
ระบบ SmartQ ในบริษัทส่งข้อมูลคิวขึ้น Firebase Realtime Database ทุก 1 นาที
หน้านี้อ่านได้เฉพาะข้อมูลของทะเบียนที่พิมพ์ (`/q/<เลขทะเบียน>`) ดึงรายการทั้งหมดหรือเขียนข้อมูลไม่ได้ (ดู `database.rules.json`)
ข้อมูลที่ส่งขึ้นมีแค่ทะเบียน ประเภทรถ คิว สถานะ เวลา และประตูขึ้นสินค้า ไม่มีชื่อคนขับ น้ำหนักสินค้า หรือบริษัทขนส่ง

## แก้ไขหน้าเว็บ
แก้ `index.html` แล้วเปลี่ยน `VERSION` ใน `sw.js` ทุกครั้ง มือถือคนขับจะได้เวอร์ชันใหม่
